# CLI 确认与项目弹窗修复

日期：2026-09-14

## 修复范围

- CLI 执行前不再调用浏览器 `window.confirm`，使用应用内原生 HTML dialog 异步等待明确确认。取消、Esc、遮罩关闭和任务中止均不启动 CLI，也不改变连接健康状态。
- 每次打开重置授权结果，关闭清理中止监听，恢复触发控件焦点；后端 `allowUserProfile` 校验不变。用户可主动勾选“本次会话使用此执行端不再询问”，仅确认后在内存记录授权；切换执行端、权限说明变化或重启后重新询问。
- 正式提交后清空发送的输入草稿，取消确认不清空；重试使用已发送消息，不清空正在编辑的新草稿。失败说明指向对话区原消息与“重新生成”入口。
- 我的项目弹窗补齐独立内边距、项目数量、当前项目标识、更新时间、空状态和操作分组。跟随浅色/深色主题，小窗口允许纵向滚动，长名称换行。
- 点击弹窗内部留白不再误判为点击遮罩。
- 不修改项目存储结构，不加入初始示例数据。
