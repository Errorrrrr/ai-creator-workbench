# v0.13.0 发布说明

## 清爽工作台与逐镜检查

- 剧本与分镜路径统一为“写剧本 → 定形象 → 做分镜 → 导出”四阶段。前期资料仍可从目录打开，说明和低频操作按需展开。
- 浅色使用灰白底色，深色使用石墨底色；统一字号和留白，减少重复容器，为图片留出空间。
- 分镜以图片网格展示。点击图片进入大图检查，在同一处查看实际固定参考、填写备注、调整画面或切换版本。
- “确认并看下一镜”在保存成功后才前进；失败保留当前镜头、备注及原审核状态。修复 macOS WebKit 焦点刷新导致首次点击图片失效的问题。
- 主按钮按当前范围提示下一步，缺图时只准备缺失镜头的生成计划；仍须明确确认后提交。已有图片不会因为导航或视觉检查而重新生成。

## 分集、分场与连续性

- 目录按“集 → 分场 → 分镜”展示。整集剧本可先预览并整理为真实分场，再按场拆镜；原文提取不改写剧本，已有镜头可明确归场并保留 ID、媒体及固定参考。
- 人物、场景和物品分别维护固定特征、剧情状态与参考图片；可采用既有素材，保留手动固定与排除选择。
- 分场记录进入状态、本场变化及结束状态。生成与导出携带相关约束，连续动作、换场、时间跳转和闪回分别处理。
- 全项目视觉基准统一画风、色彩和材质。画面、参考或相关设定变化时提示重新检查；人工审核结果与素材版本一同保留。
- CLI 素材提取等待预算扩展到 10 分钟，提供耗时与停止入口；其他文字任务仍使用原有预算，失败保留已有候选。

## 素材包与保存可靠性

- 独立设定素材包、Flow／Muse 素材包包含固定版本参考图、提示词和使用说明。上传用途与只用于视觉对照的图片分开列出。
- 导出前提示待复核镜头；缺失、截断或不匹配的媒体会阻止导出，避免交付不完整素材包。
- 完整项目包保留连续性设定、分场状态和版本关系；导入按新标识重映射并校验，避免覆盖已有项目。
- 候选采纳、镜头归场与视觉审核采用保存成功后生效的流程；失败时保留可重试内容。

## 验证与适用范围

- 681 项 JavaScript 测试、77 项 Rust 测试及语法检查通过，覆盖范围隔离、固定参考、项目恢复、原子保存和鼠标焦点时序。
- macOS Apple Silicon 本地安装版已验证图片网格、大图与参考放大、逐镜浏览、返回定位及导出菜单。合成项目验证保存失败保留备注、重试成功才前进，以及浅色／深色和窄窗口布局。
- 本次界面验收未额外调用付费图片或视频生成服务。视觉一致性仍需人工核对，外部视频平台仍采用手动素材交接。
- 桌面发布目标为 macOS 12.3 及以上、Apple Silicon；自动更新包使用独立更新签名。应用仍为 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。
