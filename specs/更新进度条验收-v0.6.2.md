# 更新进度条验收 · v0.6.2

- 下载进度条按后端实际 received / total 字节计算；显示百分比及已下载／总大小。无总大小时使用不确定进度，仅显示已下载 MB。
- 保存、安装、重启显示阶段文字及不确定进度；下载达到 100% 只表示传输结束，等待后端签名校验成功才进入保存。
- 取消、下载或安装失败后隐藏并清空进度；保存失败保留已验证包和完成进度；重启失败显示安装完成并保留重启操作。旧下载通道的迟到消息不污染新一轮进度。
- 原生验证：隔离 QA 0.6.2 使用 Debug-only 本机清单模拟 0.6.3，下载 8 MiB 限速测试数据。浅色与深色模式分别确认百分比条增长；取消后进度隐藏；无 Content-Length 时只显示已下载大小和不确定进度；无效包下载完成后签名拒绝，进度隐藏且可重试。未安装测试包，模拟 0.6.3 未公开。
- 自动化：165 项 JavaScript 测试、35 项 Rust 测试、语法和 Rust 格式检查通过；前端与隔离原生构建通过。保存／安装／重启的进度状态和失败恢复由受控异步测试覆盖。
