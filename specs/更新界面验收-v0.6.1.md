# 更新界面验收 · v0.6.1

- 最新版：显示“已是最新版本，无需更新”，隐藏下载按钮、安装包文件名和安装提示；保留重新检查和发布页。
- 有新版本且支持应用内安装：突出主要按钮“更新并重启”，隐藏手动下载按钮，说明保存和自动重启行为。
- 浏览器及不支持应用内安装的平台仍提供手动下载；检查失败不复用旧链接。
- 本地检查：语法检查、163 项 JavaScript 测试、35 项 Rust 测试、Rust 格式检查、前端及隔离原生构建通过。
- 原生验证：独立 QA 应用 0.6.1 使用仅 Debug 可用的本机清单，分别读取 0.6.1 和模拟 0.6.2，实看最新版无下载入口、新版本突出深色主要更新按钮。模拟版本仅用于界面验证，不代表公开发布。
- 发布后通过正式 0.6.0 的应用内更新升级本机，并核对版本与原项目数据；实际结果以最终交付和项目主页为准。不备份旧应用，不调用真实模型。
