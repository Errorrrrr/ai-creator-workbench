# v0.12.0 发布说明

## 镜头图片自动关联

- 图片生成完成并收录后，自动关联原镜头并设为当前选用图片；缩略图、生成页预览、版本列表和制作进度同步更新。
- 重做后的新图片自动接替旧图，旧版本继续保留。批量结果按任务所属镜头分别关联。
- 恢复分镜历史时保留该版本选用的图片，已完成或正在运行的任务不会自动覆盖恢复结果；之后主动重新生成仍会选用新图。
- 已有未关联的生成结果会补齐；保留手动选用的导入图、其他镜头图片，以及生成期间的手动选择。
- 按任务发起时间判断新旧，避免旧任务晚完成时覆盖新结果。重复刷新和重启不会反复覆盖选择。
- 图片选用与参考关联一起保存，保存失败时保留结果，刷新任务后可以重试。编辑或播放视频时暂缓版本列表刷新，结束后补齐。

## 多场批量生图与单场导出

- 分镜工具栏增加「多场批量生图」，可跨集选择多个分场，再勾选本批镜头并预览完整输入。每批最多 20 个镜头。
- 预览固定镜头、提示词与参考版本；项目、正文或输入变化后需重新预览，防止误提交和重复提交。
- 「导出 → 导出单个分场…」可独立选择一个分场，导出 Google Flow 或 Muse 素材包，不受当前查看全集范围影响。
- 素材包包含提示词与固定版本参考图，沿用已设置的导出文件夹。外部工具仍需手动复制提示词、上传图片。

## 验证

- JavaScript 静态检查与 366 项自动化测试通过，覆盖任务乱序、手动选择、保存失败重试、批量范围和导出隔离。
- 59 项 Rust 测试通过；macOS Apple Silicon 本地构建通过，安装后核对图片显示、原项目和素材完整性。
- 视频生成仍需手动选用与审核；本次验证未额外调用付费图片或视频生成服务。
