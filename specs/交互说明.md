# AI 创作工作台首版交互说明

## 1. 用户目标

面向需要持续写作的短剧、漫剧和故事创作者。首版的核心不是“一键生成视频”，而是让内容从灵感、创作简报、世界观、人物、大纲自然推进到分集与分场剧本；AI 是可切换的协作者，知识库是可核验的创作依据。

即使没有配置 AI，用户也能完成创建、编辑、版本恢复和资料检索。配置执行端后，AI 结果先进入候选区，只有用户明确采纳才会写入正文。

## 2. 主路径

1. 新建短剧、漫剧或通用故事项目，从空白项目开始。
2. 沿创作阶段填写灵感、简报、世界观、人物和大纲，再创建分集与分场。
3. 在中央编辑器写作；内容即时保存于当前浏览器。
4. 导入 Markdown 文件或选择 Obsidian Vault 目录，在本地建立索引并勾选本次需要的知识片段。
5. 选择已配置的供应商 API、Ollama 或受控 CLI，输入要求并执行。
6. 生成过程可停止；完整或部分结果保留在候选区域，不直接修改正文。
7. 用户可将候选插入光标、替换正文或追加正文；每次采纳都创建版本快照。
8. 历史版本可查看完整内容、来源方式及当次引用，并恢复为一个新的版本。

## 3. 页面结构

- 创作工作区：动态项目树、阶段推进、编辑器、AI 助手和状态栏。
- 知识库：来源列表、同步状态、片段检索、选择与引用预览。
- 连接中心：OpenAI 兼容 API、本机 CLI 和 Ollama 的独立状态。
- 命令面板：快速打开内容、切换页面和控制界面。

## 4. 状态规则

### 文档

`已保存 → 编辑中 → 保存中 → 已保存`。本地存储失败时明确显示错误；切换文档前再次尝试保存。正文采纳、恢复版本和结构删除均保持可撤销操作。

### AI 任务

`待命 → 检查执行端 → 生成中 → 候选完成 → 已采纳/已丢弃`。新任务以唯一任务 ID 隔离，切换或停止时取消旧请求，过期返回不能覆盖新内容。失败时保留已有部分输出，并在独立区域显示鉴权、限流、模型缺失、CORS、CLI 登录或超时错误。

### 知识库

`未连接 → 读取中 → 建索引 → 可用`。来源文件只读；新导入片段写入浏览器本地索引。搜索无匹配时显示空状态，不用 0% 结果制造“已命中”的错觉。被截断或因容量未收录的来源必须如实显示。

### 连接

- 未配置可用执行端时，AI 生成会提示先完成连接；本地写作不受影响。
- API/Ollama 只有真实检测成功才标记可用；修改地址、模型或密钥后状态立即降级为待检测。
- CLI “已安装”不等于“已登录”。只有实际成功生成后，当前会话才显示可用。
- Apple Silicon 上检测到 Intel 二进制时显示“兼容模式 · 实验”，不宣称原生稳定。

## 5. 知识检索与引用

- 用户通过文件选择器授权 `.md`、`.markdown`、`.txt` 文件或目录；页面不能凭空读取磁盘路径。
- Obsidian 接入指“选择 Vault 目录并只读导入 Markdown”，不接管 Obsidian 应用，也不写回 Vault。
- 文本优先按段落、句末或换行等自然边界切片，并生成 384 维哈希词向量；余弦分数用于本地排序，低于最低阈值的结果不展示。
- 本轮最多保留 160 个片段，避免 `localStorage` 失控；大量导入时按来源均衡保留并明确提示截断。
- 最多选择 6 个片段随一次请求发送；发起生成时冻结所选片段快照，候选区和版本历史展示的是这次真实发送的引用。

## 6. AI 执行端

### OpenAI 兼容 API

测试读取 `/models`，生成调用 `/chat/completions`，同时兼容 SSE 流式和普通 JSON 返回。Key 只保留在当前页面内存，刷新后重输。浏览器 CORS 失败单独提示。

### Ollama

检测 `/api/tags` 并校验配置模型，生成调用 `/api/chat`。服务未启动、没有模型和指定模型不存在是三个不同状态。

### 本机 CLI

页面只能传 `driverId` 与结构化消息到 loopback 运行桥。服务端从固定白名单选择可执行文件与参数，在独立临时目录中以 `shell: false` 运行；请求大小、并发、输出和时间均有限制，连接关闭会终止任务。

当前仅 Claude 驱动具备生成通路：必须使用 `--bare`、禁用工具、禁用会话持久化、临时隔离 HOME，并由启动进程显式提供 `ANTHROPIC_API_KEY` 后才开放。Codex 和 Gemini 只做检测。CLI 仍可能调用云端模型，界面需持续提醒用户所选内容与知识会发送给对应服务。

## 7. 键盘、可访问性与响应式

- `⌘/Ctrl + K` 打开命令面板并把焦点移入搜索框。
- `⌘/Ctrl + S` 保存，`⌘/Ctrl + Enter` 执行 AI，`Esc` 关闭弹层或停止任务。
- 所有图标按钮有可访问名称，焦点环可见；版本和选项卡支持键盘切换。
- AI 流式区域只在完成、停止或失败时播报，避免逐字打扰辅助技术。
- 小于 1100px 时 AI 侧栏成为覆盖抽屉；小于 768px 时项目树也成为抽屉。打开后焦点进入面板，关闭后回到触发控件，正文不横向溢出。

## 8. 当前边界

首版暂不包含视频/图片生成、多人协作、云同步、Obsidian 双向写回、标签与双链解析、任意 Shell、插件市场、多 Agent 无人值守流水线和成本大屏。当前仅保存一个浏览器项目；正式桌面版再迁移至 Tauri、SQLite、系统凭据库和可替换的语义 Embedding/向量存储。
