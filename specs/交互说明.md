# AI 创作工作台交互说明

更新日期：2026-10-05。本文描述当前源码提供的行为和边界，不作为真实桌面、模型服务或正式发布已经验收的证明。

## 用户目标与主路径

面向持续写作的短剧、漫剧和故事创作者，帮助内容从灵感、创作简报、世界观、人物、大纲推进到分集与分场。没有 AI 连接时，项目、灵感、文本编辑、版本与本地检索仍可使用。

1. 创建短剧、漫剧或通用故事项目，或先在独立灵感库记录想法。
2. 填写创作资料，按需要创建、重排分集与分场。
3. 在正文编辑器写作，自动保存；重要节点手动保存快照。
4. 导入资料，检索并勾选本次需要的知识；查看“发送范围”。
5. 选择执行端，发送创作要求，审阅候选。
6. 将候选插入、追加或替换，检查历史版本。
7. 导出交付稿或 JSON 备份；完成的项目和灵感可归档，之后恢复继续创作。

## 页面与视觉结构

- **创作工作区**：项目树、阶段推进、文档视图、正文、AI 助手及保存状态。
- **灵感库**：独立于项目的列表和编辑器，提供搜索、归档筛选、Markdown 导出与完整备份入口。
- **知识库**：导入报告、索引统计、文本/语义检索、所选引用、来源同步和发送预览。
- **连接中心**：API、CLI 和 Ollama 独立检测与选择。
- **我的项目**：活动/归档列表、容量概览、备份、恢复与当前项目操作。
- **命令面板**：搜索内容、快速前往页面及常用操作。

采用暖白纸面、墨色文字与琥珀强调，浅色和深色使用统一层级。编辑器获得主要空间；项目、灵感、知识和连接卡片遵循相同字体、圆角、边界与焦点反馈，不加载网络字体。

## 项目与保存

首次启动没有示例项目。新项目为空白内容，不覆盖已有项目。创建或切换前尝试保存当前项目；保存失败时留在原上下文并提示。

保存状态从编辑中、保存中进入已保存，失败时明确显示错误，草稿仍留在当前页面。浏览器写入 IndexedDB，原生桌面写入 SQLite；事务和库版本号用于避免部分写入及旧窗口覆盖新版本。

项目树支持创建分集与分场、修改名称与元信息、排序、复制、删除及删除后的撤销。Markdown 导出顺序以当前幕、集、场结构为准；核心资料先输出，孤立但可恢复的文档保留在末尾。

“归档当前项目”保存当前项目内容到归档区并移出活动列表；活动库空间随之释放。通过“查看归档项目”选择“恢复并打开”。恢复仍受活动库容量限制，失败时不得删除归档原件。

## 灵感库

灵感无需绑定项目。标题与正文通过表单校验后保存；可搜索、编辑、追加到当前项目核心灵感，追加不会删除原灵感。

归档后的灵感在归档筛选中可查看，正文只读，按钮变为“恢复灵感”；恢复后才能继续编辑或追加。归档只是状态变更，灵感仍占用活动库空间。

切换灵感或归档筛选时，如果存在未保存修改，会提示是否放弃。保存过程中相关输入与操作暂时禁用，重复保存等待同一任务。

“导出 Markdown”包括活动与归档灵感，归档项带标记；需要可恢复 JSON 时使用“完整备份”。单项目备份不含独立灵感库。

## 快照与候选采纳

“保存快照”将当前可编辑视图内容记录为手动版本；空内容和历史只读视图不能建立手动快照。AI 采纳保存采纳前内容及新内容快照，记录来源方式和本次实际知识引用。

历史视图可选择版本、查看全文，再“恢复为新版本”；已有历史不被原位改写。自动保存与版本快照用途不同，普通每次输入不会都建立一个可选历史版本。

AI 内容始终先进入候选区。停止任务可保留已经收到的部分内容；失败时展示具体错误，仍可处理已收到内容。

- 插入使用编辑器当前选择范围，追加放在当前内容末尾。
- 生成后正文已变化时，替换被拒绝，提示使用插入或追加保留修改。
- 采纳期间禁止再次采纳、丢弃或重试，避免重复提交。
- 保存失败且没有新编辑时，正文、撤销栈和版本状态回到采纳前，候选保留重试。
- 保存等待期间有新编辑时，保留候选与新增输入构成的正文，维持未保存错误状态，并清除已应用候选，避免再次写入。
- 切换文档或项目时，过期候选不能写入其他文档；任务 ID 隔离旧请求和迟到的输出。

## 备份与恢复的三种语义

### 外部 JSON 备份

“备份当前项目”包含该项目的正文、结构、版本和知识资料。“备份全部项目与灵感”包含活动项目、归档项目、全部灵感及兼容迁移保留的旧项目副本。

两种备份均不含连接配置、密钥和可重建向量。恢复后文本检索向量本地重建，语义索引需用户重新建立。

“恢复备份”识别单项目与完整库格式，校验通过后导入新标识的独立副本；现有项目和灵感保留。容量不足或格式无效时提示失败。备份上限为 512 MiB。

完整备份优先保存当前内容；保存失败时仍可导出已提交的库，并尝试额外导出当前项目草稿。未通过校验的灵感草稿不保证进入文件，界面需明确提示。

### 上一份内部快照

每次库成功更新保留前一份已保存状态。点击“恢复上一份内部快照”先展示范围并确认，然后将整个库回到该状态；当前已保存状态成为新的上一份快照。

此操作不会保留未保存草稿，恢复前应先保存或导出。只保留上一份且随新写入滚动替换，不提供长期恢复时间线。无其他写入时可再次恢复回到前一个已保存状态。

### 启动异常恢复

库校验或载入失败时隐藏普通工作台，显示独立恢复面板，提供导出原始数据、恢复上一份内部快照、重新打开。错误详情及导出路径可换行，长内容可滚动，按钮在小屏保持可达。

原始数据导出用于排障与人工恢复，不直接作为普通项目/完整库备份导入。

## 知识导入、同步与覆盖率

文件选择器授权读取 `.md`、`.markdown`、`.txt`，来源只读。选择 Obsidian Vault 是目录导入，不写回 Vault，不解析双链、标签或插件数据库。

单次接受最多 80 个文件、单文件不超过 1 MiB、累计不超过 4 MiB。过大或不支持的文件跳过后继续扫描后续项，因此不会因列表前端出现大文件而少收录后面的合格文件。导入预览与报告列出跳过原因，空文件不产生片段；空报告隐藏，长列表独立滚动。

按自然边界切片后使用 384 维稳定哈希词向量做本地文本检索，每项目最多 2,000 个片段。超过容量时显示实际保留数量；低相关结果不作为命中展示。

选择本机已安装的 Ollama Embedding 模型可建立语义索引。界面显示“已索引 / 总片段”、待更新数及建立进度；未变化的片段复用缓存，删除和修改后清理失效向量。关闭语义检索后继续使用文本检索；模型缺失、接口失败或向量无效时明确提示，不自动下载模型。

每个来源支持重新选择目录同步；这是用户触发动作，不是文件监听。同步会更新增删改，在移除旧文件前要求确认完整目录；未变化内容的已选引用保留，失效引用清理，删除来源时清理对应缓存。

## 请求准备与引用准确性

AI 助手中的上下文勾选控制上游资料、人物和知识；“发送范围”展示条目、字符数和截断状态。生成开始时冻结消息与实际引用，后续异步确认和界面变化不改写该请求。

总预算为 24,000 字符，创作要求最多 12,000 字符并完整保留；这里不等于模型 token 预算。正文/大纲上限 9,000 字符，上游每篇 2,800，引用笔记 1,500，最多 6 条知识、每条 900；总预算不足时进一步缩减上下文。

在引用检查视图发起请求时同时提供真正正文和引用笔记，避免只核对笔记。截断项带明确标记；没有实际发送的知识不进入候选引用，部分发送的片段仅记录发送部分。取消勾选只影响后续请求，历史引用保留当时快照。

## 执行端与状态

API/Ollama 检测与生成分离；修改地址、模型或密钥后回到待检测。“设为当前 AI”只选择后续执行端。CLI 已安装不等于已登录，也不证明额度或真实生成可用。

- **OpenAI 兼容 API**：`/models` 检测，`/chat/completions` 生成，兼容 SSE 和 JSON。浏览器直连受 CORS 限制；原生由 Rust 请求。
- **Ollama**：`/api/tags` 检测和 `/api/chat` 生成，需要本机服务和模型；Embedding 经 `/api/embed`。
- **Codex**：已提供只读、非持久化执行通路，先 `codex login`，读取最后答复，忽略用户自定义供应商配置与规则。
- **Claude**：可用显式 API Key 或既有登录态。Key 分支使用裸模式、无工具、临时隔离 HOME；登录分支关闭普通工具/MCP/技能/hooks 等，组织托管策略仍可能生效。
- **Antigravity**：通过 `agy` 固定参数运行，先在终端登录；用户配置、插件/hooks 及权限规则仍可能生效。
- **Gemini**：仅检测安装，不开放生成。

CLI 发送前确认账号与上下文，可勾选当前会话同一执行端不再询问；实际请求可能使用云服务并消耗账号额度。固定白名单驱动、临时目录、请求/输出/并发/超时限制不等于操作系统级隔离。Apple Silicon 上的 Intel CLI 标明兼容模式。

API Key 默认只存会话内存，macOS 可选择钥匙串，密钥不写入项目或备份。原生不需要常驻 Node 服务；浏览器 CLI 桥只监听 loopback 并校验同源请求。

## 关闭、键盘与响应式

原生关闭先阻止立即退出；采纳或知识保存正在进行时提示等待。有未保存灵感时等待灵感保存，再等待项目保存，仍有草稿或任务则不销毁窗口。浏览器离开页面时检查未保存状态并提示，不能保证浏览器崩溃或强制退出时保存。

- `⌘/Ctrl + K`：命令面板并聚焦搜索框。
- `⌘/Ctrl + S`：保存当前文档，灵感页保存当前灵感。
- `⌘/Ctrl + Enter`：执行 AI 请求；`Esc`：关闭弹层/抽屉或停止任务。
- 焦点环可见，选项卡支持方向键，候选在完成、停止或失败时播报，避免逐字打扰辅助技术。
- 1099px 以下助手为抽屉，899px 以下项目目录也为抽屉；手机仍保留快照、历史、撤销/重做等主要入口。
- 打开抽屉移入焦点，关闭后回到触发控件；灵感在 699px 以下单栏，长路径与报告允许换行。
- 系统开启减少动态效果时，持续动画及过渡被缩减。原生窗口最小 1024 × 700，375/768px 布局主要用于浏览器。

## 数据容量与验收边界

活动库逻辑上限 64 MiB，归档项目 448 MiB，备份 512 MiB；浏览器仍受自身配额限制。SQLite 的 WAL 和内部快照会占用额外物理空间。浏览器与桌面独立保存，通过 JSON 迁移，不自动同步。

当前不包含视频/图片生成、多人协作、云同步、后台文件监听、Obsidian 双向写回、任意 Shell、插件市场或多 Agent 无人值守创作。macOS arm64 提供构建配置，当前 ad-hoc 签名；正式签名公证、安装/升级验证、自动更新和 Windows 发布尚待完成。

仓库提供静态检查、Node 回归测试、Rust 测试与构建命令。函数模拟及本地协议测试不能证明真实 WebView、真实供应商/CLI 登录态、Embedding 模型或正式发布已经通过验收。
