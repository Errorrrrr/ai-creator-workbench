# v0.4.2 项目删除

## 使用方式

打开“我的项目”，在活动项目或归档项目右侧点击“删除”，核对项目名称与删除范围后选择“永久删除”。默认焦点在“取消”，关闭对话框或按 Esc 不会删除。

删除包括项目正文、结构、历史版本、知识资料、分镜，以及项目内的图片、视频、素材登记和任务记录。内部上一份快照会同步移除该项目，无法用快照撤销删除。已导出的备份、外部原始文件、其他项目、独立灵感及全局连接设置保留。

删除当前项目会切换到其他活动项目；删除最后一个活动项目后展示空项目状态。删除其他项目会先保存当前编辑内容。文字生成或目标项目媒体任务仍在运行时，需先停止并等待结束。

## 数据一致性

项目记录、归档、内部快照和媒体清理队列在同一 SQLite 事务中更新；写入失败不改变当前项目。已删除项目的标识不可被迟到的媒体写入或旧快照重新启用。恢复外部备份仍创建独立的新项目。

媒体文件在事务提交后按登记路径清理。中断或文件访问失败会保留清理队列，在下次启动时重试；界面会提示有待清理文件。清理校验路径边界并保留其他项目仍引用的文件。浏览器版在单个 IndexedDB 事务中删除项目及快照中的对应记录。

## 验证

- Node 回归：项目删除、失败重试、当前编辑保存、取消、生成中阻止等。
- Rust 回归：SQLite 事务回滚、归档与快照清理、迟到写入拒绝、媒体清理重试、路径越界与符号链接防护、其他项目文件保留。
- 隔离浏览器实测：取消确认、活动/归档/最后一个项目删除、保留项目正文、快照恢复及刷新后持久化，无 JavaScript 异常。
- 发布仍通过 GitHub Actions 构建并校验 macOS Apple Silicon 的 app、DMG、更新清单与 SHA-256 文件；正式发布状态以 GitHub Releases 为准。
