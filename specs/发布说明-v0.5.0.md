# AI 创作工作台 v0.5.0

本版本新增候选稿保留、修改差异审阅和写作区空间优化，并保留 v0.4.2 的项目永久删除及关联媒体清理功能。公开安装包与发布状态以 [GitHub Releases](https://github.com/Errorrrrr/ai-creator-workbench/releases) 的实际附件为准。

- **候选稿保留**：按项目、文档和页签保留待审稿，切换内容或重载后可继续审阅；重新生成新增一稿，停止或中断保留部分内容。生成要求、实际发送的上下文、生成时原文和时间一同保存，并纳入项目备份。每项目最多保留 100 稿，到限后由用户采纳或移除，不自动删除旧稿。
- **修改差异审阅**：文字候选和项目计划中的文档修改提供逐行增删高亮、变更统计、前后跳转与完整前后文本。生成后原文已修改时继续阻止替换；项目计划保持整批校验与原子采纳。长文本采用有界比较，并明确提示展示回退范围。
- **写作区空间优化**：合并重复标题，压缩常驻步骤、工具栏与纸面头部；创作目标和助手上下文可按需展开，助手为候选与差异保留阅读空间。保持暖纸、墨色、琥珀配色及既有写作字体，保留窄屏操作与键盘焦点。

分镜候选的手动 JSON 校正也会保存；文字、项目计划与分镜成功采纳时，在同次保存中移除对应待审稿，保存失败时保留候选或回滚。手工计划不会移除其他 AI 待审稿。

本地 JavaScript 检查、151 项 JavaScript 测试、34 项 Rust 测试及前端构建通过。独立应用标识的 macOS debug 原生包已构建、签名并启动，使用本机固定响应完成文字候选生成与重试保留、两处差异跳转、慢流生成中正常关闭后 SQLite 恢复，以及文字替换与项目计划采纳验证；成功采纳只移除对应来源稿。最终修正版再次通过 JavaScript 检查与 151 项测试，并在重建的原生包中复核重启恢复、采纳及正确播报。浏览器另覆盖分镜 JSON 编辑、断点布局与浅深主题。本轮没有调用真实 AI、图片或视频供应商，完整范围见 [2026-10-15 优化验收](优化验收-2026-10-15.md)。

旧项目可继续打开；升级前建议备份项目。备份导入为独立项目后，旧操作计划与分镜候选保留原目标标识，需重新生成才能执行；文字候选仍可审阅和采纳。浏览器关闭不能保证最后一个未落盘片段，应留意保存状态。其他设备与旧版本的升级组合仍需按环境验证，具体安装记录以交付回执为准。

目标平台为 macOS Apple Silicon，最低 macOS 12.3。当前构建配置采用 ad-hoc 签名，尚无 Developer ID 签名或公证；本版本不新增真实视频验收结论。
