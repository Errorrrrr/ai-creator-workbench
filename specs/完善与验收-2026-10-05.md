## 当前结论

本轮完成了审查中 3 项 P1、12 项 P2 的针对性修复，补齐归档、完整库备份、内部快照恢复与手动版本，并统一创作区和管理页的视觉样式。适合继续进行真实桌面和真实执行端的小范围验收；不能据此宣称已达到正式发布条件。

主要路径现在包括：多项目创建与切换 → 前期创作 → 分集分场 → 自动保存/手动快照 → AI 候选审阅与采纳 → 结构化备份/Markdown 导出；灵感与知识来源可独立管理。

## 修复与交付

| 范围 | 最终行为 |
| --- | --- |
| P1-01、P2-01：候选采纳 | 保存时锁候选操作；失败时仅在编辑修订号与内容均未改变时回滚。等待期间新输入保留并明确标为未保存。采纳前保留必要快照，重复点击不重复写入。 |
| P1-02：桌面退出 | 原生关闭先保存灵感再保存项目，复核新输入与正在保存状态；失败保留窗口。项目过渡期间禁止销毁。 |
| P1-03：备份可恢复性 | 项目和完整库备份去除可重建向量；活动库 64 MiB、独立归档 448 MiB、备份/导出 512 MiB。启动、保存、导入共用结构和引用校验。 |
| P2-02、P2-09：生成上下文 | 在异步操作前冻结消息与实际引用；引用页包含真正正文。总计 24,000 字符预算保留完整用户要求，单项截断明确展示，超过 12,000 字符的要求明确拒绝。浏览器 CLI 不再静默截断消息。 |
| P2-03：导出顺序 | 按前期文档、幕、集、场遍历；保留未归类文档，避免重排后导出顺序错误。 |
| P2-04～07：知识一致性 | 片段 ID 不受同步时间影响；无变化内容可复用缓存。删除/变更资料同时清理索引、选择与语义缓存；保存失败回滚，不误报成功；取消读取时的隐式截断。 |
| P2-08：CLI 取消 | 在第一个异步等待前监听取消，查找执行文件或读取请求期间断开时不会继续启动 CLI。 |
| P2-10～11：连接检测 | 检测使用配置中的地址，支持自定义端口和 IPv6；模型目录必须合法且非空，已选模型必须存在。浏览器与桌面使用一致的地址边界，并拒绝重定向。 |
| P2-12：键盘导航 | 方向键切换文档视图保持标签焦点，可连续导航。窄屏图标有明确无障碍名称。 |
| 流式与超时 | 桌面通过带 taskId 的事件增量输出，最终结果校准；浏览器统一解析 SSE/NDJSON/JSON，处理 UTF-8 跨块、错误、截断、取消、响应上限和超时。 |
| 项目过渡竞态 | 新建、切换、归档、恢复、导入、重命名期间锁编辑和快捷键；异步回调重新检查所属项目。灵感保存中不重置表单。 |
| 项目生命周期 | 活动/归档列表、归档与恢复；归档可直接保留未保存正文并释放活动容量，不要求先写入已满的活动库。 |
| 恢复与容量 | 展示活动和归档载荷；完整库备份包含活动项目、归档与灵感。外部备份导入生成新 ID；内部上一份快照可恢复并反向恢复。无变化保存不覆盖有用的上一份状态。启动损坏时提供原始导出、恢复和重试。 |
| 灵感 | 保存失败保留输入，归档可只读查看与恢复；Markdown 导出包含归档；完整库备份支持结构化恢复。追加前复核目标项目。 |
| 知识导入 | 单次最多实际收录 80 个 MD/TXT 文件、单文件 1 MiB、总计 4 MiB；预览和结果列出跳过原因，超大文件不会阻断后续合格文件；显示语义索引覆盖率。 |
| 工程 | 新增自动发现的 JS 语法检查、Node 行为回归、Rust 回归和 GitHub Actions 配置；构建包含新增浏览器模块。 |

## 界面调整

- 使用暖纸色、墨色和琥珀强调色，统一明暗主题、边框、卡片、按钮、表单和对话框。
- 扩大正文阅读区，调整项目导航与 AI 面板宽度；用更清晰的字号和留白区分标题、正文、状态和次要提示。

- 补充上下文发送范围、导入预览、容量摘要、归档过滤和启动恢复界面；保留键盘焦点与减少动画偏好。

设计规范在 `design-system/ai-creator-workbench/`；使用说明同步更新到 [README](../README.md) 与 [交互说明](交互说明.md)。

### 实际浏览器交互

使用独立 `http://127.0.0.1:4187` 与合成故事数据，未操作用户真实项目库：

1. 新建项目，编辑正文，保存手动快照，修改后恢复为新版本；刷新保留内容。
2. 新建分集和分场、保存正文；已写分场进度正确更新。
3. 保存灵感、追加至当前项目，归档后只读查看，再恢复继续编辑。
4. 项目归档后从活动列表移除，归档列表恢复后正文、结构、版本与已采纳内容保留；对话框在过渡后解除忙态，可继续操作。
5. 配置本机合成 OpenAI 兼容服务（4188），测试模型目录成功；观察增量文本，再看到完整候选；正文在采纳前不变，追加后创建新版本。未调用真实模型或 CLI 生成。
6. 检查 1440、1024、768、375 宽度；明暗主题、创作区、AI 抽屉、知识页与连接页可用；页面横向宽度未超出视口。375 宽度专注按钮完整保留 44px，连接区边框为 1px。
7. 最终浏览器控制台未出现 error/warn。

知识文件选择自动化未返回可确认的导入结果，故未计为端到端通过；导入预算与跳过逻辑有自动化测试。完整备份文件的浏览器下载/文件选择恢复未作为本轮 UI 验收结论，序列化与往返恢复已由数据测试验证。

## 仍需完善与验证

按下一步优先级排列：

1. **真实 macOS 桌面验收**：Keychain 存取、原生关闭与退出、数据库升级、权限目录选择、超大库恢复、安装包重打包和旧版本升级。原生事件增量输出需真实 Tauri 窗口复核。
2. **真实执行端验收**：至少一个 OpenAI 兼容服务、Ollama 自定义端口与本机 Embedding、已登录 CLI；验证账号错误、额度耗尽、网络中断和长输出。模型目录可用不保证生成权限或质量。
3. **长期数据规模**：活动库仍为整库 JSON 事务，已移除可重建向量并分离归档，但还未改为逐文档增量存储。内部只保留上一份快照，不能替代定期外部备份；灵感归档不释放活动库容量。
4. **创作体验**：候选草稿持久化、多候选比较、清晰的审核/完成状态、人物/地点的结构化资产与连续性检查。当前进度仅统计有正文的分场。
5. **知识能力**：大 Vault 增量更新、后台监听、双链/标签解析、检索质量评测、Embedding 模型切换和迁移。当前为授权导入与手动同步，不能宣称已完成 Obsidian 深度集成。
6. **正式交付**：签名、公证、更新机制、跨平台与键盘/屏幕阅读器完整验收。视频、配音、分镜和协作属于后续产品范围，本轮没有伪造这些功能。
