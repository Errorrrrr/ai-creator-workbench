# 灵感库与窗口拖动修复

- 灵感库是本机共享资料，不依赖项目，不创建示例。数据存入现有项目库的 inspirations 字段，与项目保存共用事务队列。
- 路径：灵感库 → 新增或选择 → 填写标题和正文 → 保存 → 搜索或追加到当前项目核心灵感。追加不覆盖原文，不自动调用 AI。
- 空态显示新增提示，搜索无结果单独提示。表单提交校验标题及正文；提交中禁止重复提交，失败保留输入并显示可重试错误。
- 切换选中灵感或新建前确认放弃未保存输入；切换页面保留草稿。关闭应用时有草稿则阻止关闭并提示先保存。不提供删除入口。
- 保留系统原生标题栏作为稳定拖动区域；工具栏启用深层非交互区域拖动，按钮仍可点击；显式授予 start-dragging 权限。验证原生窗口位移及按钮响应。
- 灵感库提供独立 Markdown 导出，不包含在单个项目 JSON 备份中。
