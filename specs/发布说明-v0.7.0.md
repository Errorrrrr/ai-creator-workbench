# AI 创作工作台 v0.7.0

- 新增“人物小传 → 生成角色正脸与三视图”，素材库也提供“从人物小传生成角色图”入口。
- 支持从 Markdown 人物表格或分节标题选择单个角色，核对小传、补充外观和视觉风格，并选择已有角色图作为参考。
- 生成一张完整角色设定图：左侧正脸特写，右侧正面、90 度侧面、背面三张全身视图，统一脸型、发型和服装。
- 图片生成完成后自动保存到原项目的“角色”素材；同角色再次生成保留独立版本，已有选用版本保持不变。任务中心支持查看状态、停止等待及恢复收录。
- 静态图片改用内置解码，PNG、JPEG、WebP、GIF 的导入与生成结果收录无需额外安装 FFmpeg；保留实际像素、尺寸和内存限制校验。视频仍需本机 FFprobe／FFmpeg。

生成前需在连接中心配置支持图片生成的执行端。角色设定图的构图与一致性是生成要求，实际结果仍需审阅。

适用于 macOS 12.3+、Apple Silicon。0.6.0 起可在应用内更新；更早版本首次升级需安装 DMG。应用采用 ad-hoc Apple 签名，尚未做 Developer ID 签名或公证；更新包独立签名校验已启用。
