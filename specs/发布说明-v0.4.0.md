# AI 创作工作台 v0.4.0

## 更新内容

- 项目内新增创作、分镜、素材工作区和可跳步的创作流程；首次启动与新项目仍为空白，不带示例数据。
- 按文字、拆镜、图片、视频分别选择已有 API／CLI 资源，全局默认与项目覆盖分开；选择失效时明确报错，不自动换模型或计费路径。
- 助手支持讨论、文字候选和受控项目修改计划；完整发送范围可审阅，计划先预览后采纳，保留原文版本。
- 分镜可编辑画面、运镜、起止状态，固定具体参考版本；图片生成结果先自动收录为候选，再明确选用。
- 新增媒体任务中心、一次确认的批量计划、取消与分阶段恢复；未知提交不自动重复生成。
- 官方原生文件选择器与受控媒体预览；完整 `.acwpack` 项目包包含真实媒体，导入为独立项目并保留原项目。
- Codex 沿用现有登录态及本机有效模型设置，提供可选规划模型覆盖与安全错误提示，不再把 CLI 版本当作模型 ID。

## 已验证范围

使用现有 Codex CLI 在 macOS 隔离桌面环境完成灵感、大纲、剧本、局部修改、六镜头及一项带固定图案参考的真实图片。候选明确选用、正常重启、完整项目包恢复与真实文件一致性通过。该图案参考验收不等于跨镜头人物身份或视频一致性保证。

## 使用前提与边界

- 安装包仅支持 macOS 12.3+、Apple Silicon（M 系列），提供 DMG、app ZIP 和 SHA256SUMS。
- 当前是 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。
- 媒体导入、图片收录及视频抽帧需要本机已有 FFmpeg 和 FFprobe，安装包不携带、不自动下载。纯文字不依赖它们。
- Codex 原生图片是版本相关的个人实验性适配；需要兼容的现有 CLI 和可用账号额度，不保证任意账号、模型或升级版本可用。
- 视频按本轮范围先提供通用适配框架，真实视频生成未验收；不包含应用内粗剪／成片渲染或 Windows 安装包。
- 应用内“检查更新”仅打开发布页或下载链接，不自动替换应用。

## 升级与备份

升级前保留原项目并导出文字／结构备份；已有媒体请另导出完整 `.acwpack` 项目包，旧 JSON 备份不包含媒体字节。关闭旧应用后手动替换。含新媒体结构的数据不要未经转换交给旧版程序。
