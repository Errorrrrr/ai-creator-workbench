# AI 创作工作台 v0.8.0

- 分镜工作区新增「导出 Google Flow 素材包」：按镜头整理视频提示词、固定版本参考图、首尾帧用途和中文操作说明，方便逐镜头上传到 Google Flow。
- 新增「导出 Muse 聊天素材包」：生成可发送到 muse.ai 的 Meta Muse Video 请求，包含镜头画面、动作、运镜、对白、目标时长／画幅和附件对应关系，另附修改消息模板。
- 素材包保存到系统下载目录。每个镜头拥有独立文件夹，同一镜头中的相同图片只复制一次，同时保留多种参考用途。
- 没有参考图、剧本来源变化、视频续接输入未导出等情况会明确标注；绑定图片版本或文件缺失时停止导出，清理不完整目录，原项目和素材保持不变。

两种导出均无需配置视频 API，不会自动上传素材或提交生成任务。素材包供手动复制提示词和上传图片使用，并非平台一键导入格式。生成时长、参考数量、首尾帧、对白及声音能力以所用平台和账号实际支持为准。本版不包含源视频导出。

适用于 macOS 12.3+、Apple Silicon。0.6.0 起可在应用内更新；更早版本首次升级需安装 DMG。应用采用 ad-hoc Apple 签名，尚未做 Developer ID 签名或公证；更新包独立签名校验已启用。
