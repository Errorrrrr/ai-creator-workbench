# AI 创作工作台 v0.9.0

- 分镜按分集、分场显示，保留全集入口；AI 拆镜关联任务和执行状态，执行期间阻止重复提交，采纳或替换成功后清除对应候选，并标明候选生成时间。
- 自动识别镜头中的角色、场景与道具参考图，已有镜头和后续补图均可关联；内容变化后清理失效的自动关联，保留手动选择并提示待核对项目。
- 分镜详情整理为「内容／参考／生成／版本」四个页签，增加镜头完成状态、生成条件提示和创作步骤定位，简化整体排版与窄屏交互。
- 增加「回填外部视频」：支持读取 Flow／Muse 导出清单，批量导入成片、核对镜头匹配后关联；同镜头冲突、来源变化和失效目标需重新确认。
- 区分剧情时长与视频生成时长，生成前检查 Veo 时长、画幅、参考输入和续接条件，批量操作集中展示不兼容项。
- 连续性检查自动准备世界观与上一场结尾，可预览、调整上下文后发送；手写参考笔记独立保存，恢复版本前自动保留当前内容。
- 统一所有 CLI 的设置入口与全局代理配置，支持系统代理、手动代理和直连；Claude API Key 收入自身设置并标明可选，安装检测与实际调用结果分开显示。
- 修复项目切换、删除、归档、素材草稿、保存失败、候选采纳和安装更新时的状态衔接与内容保护问题。

Flow／Muse 素材包仍用于手动上传提示词和参考图；回填操作只导入已有视频，不会自动提交外部平台生成。真实生成能力取决于供应商、账号和模型，本轮发布验收不包含收费图片或视频生成。

适用于 macOS 12.3+、Apple Silicon。0.6.0 起可在应用内更新；更早版本首次升级需安装 DMG。应用采用 ad-hoc Apple 签名，尚未做 Developer ID 签名或公证；更新包独立签名校验已启用。
