# AI 创作工作台 v0.10.0

- 创作区增加正文与候选的 Markdown 阅读预览、上一场／下一场导航；新增分场保留独立入口。长文续写使用正文末尾，发送范围显示实际上下文与截断情况。
- 候选可以继续修改或继续讨论，明确携带所选候选及创作要求；参考笔记可选加入 AI 上下文，也可随项目 Markdown 导出。
- 已有镜头的分场再次 AI 拆镜时，先选择替换重做、追加或仅生成候选。替换前保留可恢复的分镜历史，连同原参考图和选用媒体保存，最多保留最近 10 份。
- 视频审核绑定当时的镜头内容、参考图、生成设置和来源剧本；修改后提示重新复核。旧审核记录仍保留，缺少制作指纹时标记待复核。
- Flow／Muse 导出清单包含制作输入指纹；回填外部视频时提示导出后发生变化的字段，过期清单或没有制作指纹的旧清单需手动核对勾选。
- 新增按分集、分场汇总的制作进度看板，可查看待写、待拆镜、待补图、待选视频与待复核镜头，并直接进入对应位置。
- 素材库支持名称与版本搜索、类型及使用状态筛选、名称排序、使用位置跳转和版本并排对比；任务刷新保留素材卡片、键盘焦点与正在播放的预览。
- 当前分场或全集的选用视频可顺序连播，也可导出原视频与镜头清单，标明对白、剧情时长和实际视频时长。缺失视频会明确提示；导出保持原始文件，不拼接或转码。
- 创建、移动、复制和删除分场先完成保存再切换界面；保存失败保留原状态。普通自动保存只复制编辑中的项目，跳过未变化的归档，并合并相邻等待中的自动保存。
- 完整项目包在复制媒体前检查文件数量和容量预算；分镜历史引用随备份保留，导入时重映射；失败不留下半成品包。

已有镜头不会自动重排或删除。真实图片和视频生成取决于供应商、账号与模型，本轮发布验收不调用收费生成服务。

适用于 macOS 12.3+、Apple Silicon。0.6.0 起可在应用内更新；更早版本首次升级需安装 DMG。应用采用 ad-hoc Apple 签名，尚未做 Developer ID 签名或公证；更新包独立签名校验已启用。
