# AI 创作工作台 v0.6.0

- 桌面版新增“更新并重启”：应用内下载签名更新包，显示进度并可取消；无需手工拖动应用替换。
- 更新包必须通过签名及版本校验。安装前保存创作内容、候选稿与灵感；任务未结束或保存失败时暂停安装。
- 安装期间锁定编辑，成功后自动重启。下载、安装、重启失败有明确提示并可重试。
- 发布流程自动生成并验证签名更新包，兼容旧版本的 DMG 下载入口。

适用于 macOS 12.3+、Apple Silicon。0.5.0 及更早版本首次升级仍需安装 DMG；升级到本版后即可使用应用内更新。应用采用 ad-hoc Apple 签名，尚未做 Developer ID 签名或公证；更新包的独立签名校验已经启用。
