# 工作台页面规范

更新日期：2026-10-15。补充并细化上级 `MASTER.md`。

## 空间分配

- 桌面布局：60px 主导航、236px 项目目录、弹性正文、340px AI 助手。
- 1100–1279px：目录收窄到 224px，助手收窄到 320px。
- 900–1099px：AI 助手为右侧抽屉；正文继续占用余下空间。
- 899px 以下：目录也切换为左侧抽屉，导航宽度为 56px；正文占据其余宽度。
- 知识库、连接中心、灵感库隐藏项目目录与助手，内容最大宽度为 1180px。
- 专注模式释放目录空间；同时关闭助手时，两侧空间都归还正文。
- 不依赖仅设置 `visibility: hidden` 释放网格列；中屏仍保留正确的零宽目录轨道，小屏抽屉脱离文档流。

## 写作区

- 编辑器优先于两侧工具，纸面最大宽度 820px。
- 文档标题、标签页、可折叠创作目标、正文按顺序排列；正文周围保留稳定的间距。文档头最小高度 72px，工具按钮在桌面采用 36px 高度，窄屏保持 44px 点击区域并允许换行。
- 创作目标默认收起为 36px 高度的琥珀提示行（窄屏 44px），展开后显示完整目标与全部标签；使用原生 `details` / `summary`，支持键盘展开与可见焦点，不增加弹窗。
- 纸面头合并正文标签、场景信息与编辑入口；与文档主标题相同的纸面标题不重复显示，独立的场景标题仍保留。纸面顶部内边距 16px，头部与正文间距 12px，不牺牲正文行距。
- 正文采用宋体字体栈，纸面圆角为 12px，边界和阴影轻于浮层。
- 编辑器聚焦时显示外围焦点，避免文字区域出现多重边框。
- 当前版本、字数、保存状态贴近正文；长状态说明可以换行。
- 新增手动快照后，标题与工具栏可以分行；375px 时六个主要编辑操作仍可达，不用隐藏按钮换取空间。
- 空工作台在可用区域居中，提供清晰的新建入口。
- 项目内在主内容上方显示紧凑步骤导航：路径／序号、当前步骤选择和上／下一步，允许跳步；序号不代表完成率。步骤说明默认折叠，与步骤控件同排；展开呈现输入、执行端与输出，使用真实滚动，不覆盖正文。699px 以下路径与步骤说明共用首行，步骤选择和上／下一步在第二行，保留 44px 点击区域与完整标签，不用横向滑动隐藏步骤；全局视图与无项目时隐藏导航。

## AI 助手

- 模型选择、上下文、候选结果、输入框四区分明。
- 候选正文为 14px，1.9 倍行高，长词和路径允许换行。
- 操作按钮采用两列网格，窄屏仍保留文字。
- 输入框以清晰边界表明可编辑区域；移动设备上输入字号为 16px。
- `context-preview` 呈现实际请求说明或原文，代码内容使用可换行等宽字体，最高 340px 后内部滚动。
- `task-progress` 用统一琥珀提示展示当前阶段与进度。
- 上下文采用逐层展开：正文／选区开关、可移除对象标签、实际片段及完整请求；不另加发送确认弹窗。`@` 对象选择器提供搜索、键盘关闭和明确的无结果说明，当前文字接口的素材引用标注为“说明，不含媒体字节”。
- 已提交请求快照在候选卡片内单独保留，后续编辑上下文不会改写它。对象标签可换行，列表限定高度，浅深色均使用既有语义颜色。
- 请求类型明确区分仅讨论、文字候选与项目修改计划；讨论不提供正文采纳按钮。修改计划使用既有弹窗框架，先展示可修改目标，再展示全部改动前后内容；修改 JSON 后旧预览立即失效。一次采纳保存全部文档／镜头改动，不逐项弹确认、不隐式调用媒体生成。空白计划不填示例 JSON；错误内联保留输入，采纳时阻止项目切换及新编辑。
- 素材选择只允许同时引用的镜头和确切媒体版本，展示真实版本说明及可用预览；选用不等于审核通过。准备媒体任务的操作明确标为“继续核对”，打开既有批量计划并带入镜头与能力，不读取密钥或自动生成；混合本地改动时明确先保存、再核对媒体输入，两个阶段不混称为生成确认。

## 资料与项目

- 灵感库在宽屏采用列表与编辑器双栏；699px 以下为单栏，列表设置滚动上限，避免正文入口被无限推后。
- 项目列表保留当前状态、名称、更新时间及独立操作区。`project-list-row` 配合 `project-row-actions` 支持打开与归档/恢复按钮分开布局。
- `library-management` 用于筛选与工具操作；`storage-summary` 呈现备份和存储信息。两者均可自然换行。
- 知识来源列表、检索结果和连接卡片采用一致边界、信息字号及圆角。
- 手机连接卡片的操作区明确回到自动行，避免继承桌面的跨行位置；来源操作在小屏仍可见。
- Codex 模型设置沿用表单弹窗框架：可选模型 ID、默认行为和账号未验证说明紧邻字段，错误内联且保留输入；保存期间禁用控件并阻止关闭。取消不保存，保存不调用生成，结束后焦点返回模型设置入口；不把 CLI 检测版本显示成所选模型或图片模型。
- 归档灵感筛选为完整可点击的标签行，复选框与文字保持对齐。
- 导入报告无内容时隐藏；长文件列表允许换行，并在限定高度内滚动。项目页报告与导入弹窗预览使用同一反馈样式。

## 分镜与素材

- 项目目录顶部固定创作／分镜／素材切换，保持同一项目与助手上下文。
- 分镜采用有序卡片和详情两栏；可用宽度不足 560px 时改单栏。排序提供上移／下移，不依赖拖动。
- 素材、候选与关键帧用等比例预览，视频不自动播放；文件缺失显示可恢复原因，不替换成示例图。
- 参考用途与版本明确显示，来源过期和参考更新使用文字提示。生成完成与人工审核使用不同状态。
- 连接中心以步骤执行端呈现资源选择，空选择不偷偷回退到另一图片／视频供应商。
- 表单输入保留焦点，任务刷新不能重建正在编辑的详情；空态和错误态提供真实入口。
- 批量生成采用同一弹窗框架：选择镜头和生成能力 → 预览固定输入、参考版本、执行端和未知费用 → 一次确认。改变选择须重新预览，普通单项发送不新增确认弹窗。浏览器可以预览计划，但真实媒体提交明确仅桌面可用。
- 镜头选择提供复选框及选择前 20 项／清空按钮，不依赖拖动；长标题和版本标识可换行。任务中心按批次显示已收录与待执行数量，停止批次不删除完成结果。

## 启动恢复

- `.startup-recovery` 独立于隐藏的工作台显示，保持纸面配色、清晰标题与状态说明。
- 桌面上两个恢复操作并排、重新打开单独一行；手机按单栏展示。
- 错误和导出路径可换行，面板超过窗口高度时内部滚动，避免动作按钮不可达。

## 验收重点

1. 1440px：正文主导，目录和助手均可用，长文阅读宽度舒适。
2. 1024px：关闭助手后正文不留空栏；进入知识库或连接中心不保留目录宽度。
3. 768px：抽屉可开启和关闭；灵感双栏、项目弹窗无横向溢出。
4. 375px：按钮可以换行；灵感为单栏；项目操作、主题切换、连接操作仍可达。
5. 浅色与深色分别检查选中、禁用、错误、聚焦和空状态。
6. 开启减少动态效果后，加载反馈仍能通过文字表达，不依赖旋转动画。
7. 1280×720：创作目标收起时，正文在首屏直接可见；对比优化前测量正文起点与可见高度。展开目标或步骤说明后可滚动到完整内容，并可用键盘收起。

这些是验收要求，不代表浏览器检查已经执行；测试结果应记录在实际交付报告中。
